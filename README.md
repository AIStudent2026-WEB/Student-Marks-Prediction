# Student Marks Prediction using Machine Learning

## About the Project
This is a beginner-level Machine Learning project that predicts student marks based on study hours using Linear Regression.

## Technologies Used
- Python
- Google Colab
- Scikit-learn
- Matplotlib

## Algorithm
Linear Regression

## Dataset
The project uses a small sample dataset of study hours and student marks.

## Project Output
The model predicts marks based on the number of study hours and displays a graph showing actual marks and the prediction line.

## Learning Outcomes
- Understanding Machine Learning basics
- Learning Linear Regression
- Training a Machine Learning model
- Visualizing data using Matplotlib
